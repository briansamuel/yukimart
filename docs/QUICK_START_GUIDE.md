## 🔌 **BƯỚC 6: TEST API (30 giây)**

### **API Endpoints để test:**

#### **Thông tin Tenant:**
```bash

# HelloMart  
curl http://hellomart.yukimart.local/api/tenant/info

```

#### **Kiểm tra Authentication:**
```bash
# Sau khi login
curl http://tenant1.yukimart.local/admin/auth/check
```

#### **Lấy danh sách sản phẩm:**
```bash
# Products API (cần login trước)
curl http://tenant1.yukimart.local/api/products
```

## 🎯 **BƯỚC 7: THỰC HÀNH (Tùy chọn)**

### **Thử nghiệm Multi-Tenant:**
1. **Mở 2 tab browser**
2. **Tab 1**: Login TechMart với `owner@techmart.local`
3. **Tab 2**: Login Fashion với `owner@fashion.local`  
4. **So sánh**: Dữ liệu hoàn toàn khác nhau!

### **Thử nghiệm Role-Based:**
1. **Login Owner**: Xem full dashboard
2. **Logout và login Staff**: Xem quyền hạn chế
3. **So sánh**: Khác biệt về permissions

### **Thử nghiệm API:**
1. **Dùng Postman/Insomnia**
2. **Test các endpoint**: `/api/tenant/info`, `/api/products`
3. **Kiểm tra**: Response khác nhau theo tenant
