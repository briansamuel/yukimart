## 📋 **TECHNICAL IMPLEMENTATION DETAILS**

### **ApiOptimizationTrait Methods**

#### **Core Methods:**
```php
// Caching
cacheResponse($key, $data, $minutes)
generateCacheKey($request, $prefix)

// Field Selection
parseFields($fieldsString)
applyFieldSelection($data, $fields)

// Performance
addPerformanceHeaders($response, $startTime)
addRateLimitHeaders($response, $limit, $window)

// Pagination
optimizePagination($query, $request)

// Error Handling
errorResponse($message, $statusCode, $errors = null)
```

#### **Usage Example:**
```php
class ExampleController extends Controller
{
    use ApiOptimizationTrait;

    public function index(Request $request)
    {
        $startTime = microtime(true);

        // Generate cache key
        $cacheKey = $this->generateCacheKey($request, 'examples');

        // Try cache first
        $cachedResponse = $this->cacheResponse($cacheKey, null, 10);
        if ($cachedResponse) {
            $response = response()->json($cachedResponse);
            return $this->addPerformanceHeaders($response, $startTime);
        }

        // Process request...
        $data = $this->processData($request);

        // Cache response
        $responseData = ['status' => 'success', 'data' => $data];
        $this->cacheResponse($cacheKey, $responseData, 10);

        // Return optimized response
        $response = response()->json($responseData);
        $response = $this->addPerformanceHeaders($response, $startTime);
        $response = $this->addRateLimitHeaders($response, 60, 1);

        return $response;
    }
}
```

### **Caching Implementation**

#### **Cache Key Strategy:**
```php
// Format: {prefix}_{hash}_{user_id}
"invoices_a1b2c3d4e5f6_123"
"products_f6e5d4c3b2a1_456"
"dashboard_9z8y7x6w5v_789"
```

#### **Cache Duration Guidelines:**
```php
// Real-time data (30 seconds - 2 minutes)
Cache::remember($key, 30, $callback);    // Notifications
Cache::remember($key, 120, $callback);   // Live stats

// Frequently accessed (5-15 minutes)
Cache::remember($key, 300, $callback);   // Product lists
Cache::remember($key, 600, $callback);   // User profiles
Cache::remember($key, 900, $callback);   // Order lists

// Stable data (15-60 minutes)
Cache::remember($key, 1800, $callback);  // Categories
Cache::remember($key, 3600, $callback);  // Menu trees
```

// Before: Multiple queries

    $product->category; // N+1 problem

// After: Single optimized query

#### **Pagination Optimization:**
```php
// Optimized pagination with field selection
public function optimizePagination($query, $request)
{
    $perPage = min($request->get('per_page', 15), 100);
    $fields = $this->parseFields($request->get('fields'));

    if (!empty($fields)) {
        $query->select($fields);
    }

    return $query->paginate($perPage);
}
```
